This project was part of the React Hooks module, and is intended to introduce how Hooks – specifically `useState` and `useEffect` – work in React. Brief from Codecademy: 

>What if you could post something and know it wouldn’t live forever? In this project, we’ll build a place for our passing thoughts. Once you add a short thought, it’ll disappear after just 15 seconds.

## What did you learn?

_I'm already familiar with Hooks from React Quickly. This project helped me practice the concepts of:_
* Using Hooks with conditionals
* Passing props when using Hooks
* Using a dependency with the useEffect Hook.
